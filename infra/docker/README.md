B2B SaaS-платформа, яка застосовує методологію Win-Loss аналізу до найму та утримання працівників. Вона збирає структуровані анонімні опитування від кандидатів після етапу оферу (прийнято/відхилено) та від працівників, які залишають компанію.

## Запуск через Docker

Запускайте Compose з каталогу `infra/docker`:

```bash
docker compose up --build
```

Контейнер `web` стартує тільки після того, як PostgreSQL стане healthy. Після цього entrypoint автоматично виконує `alembic upgrade head`, а потім запускає FastAPI. Якщо міграція завершується з помилкою, застосунок не запускається.
