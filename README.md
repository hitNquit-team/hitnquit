B2B SaaS-платформа, яка застосовує методологію Win-Loss аналізу до найму та утримання працівників. Вона збирає структуровані анонімні опитування від кандидатів після етапу оферу (прийнято/відхилено) та від працівників, які залишають компанію.

## Архітектура

Технічна архітектура MVP описана в [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md).

Вона охоплює:

- HR-дашборд для завантаження резюме, роботи з профілями та аналітикою;
- FastAPI як API та оркестратор асинхронного AI-пайплайна;
- PostgreSQL на Azure з `pgvector` для реляційних даних і пошуку схожих профілів;
- цикл зворотного зв’язку після звільнення працівника;
- Docker-деплой локально та в Azure.
